# Synadata Desktop – Updates

Öffentliche Ablage für die fertigen Versionen von **Synadata Desktop** (Mac-App für Videoanalyse im Unihockey).

- **Herunterladen:** unter [Releases](../../releases/latest) die neueste `Synadata-Desktop-x.y.z.dmg`.
- **Updates:** Die App prüft `appcast.xml` in diesem Repo und aktualisiert sich selbst (Sparkle).

Alle Versionen sind von Apple notarisiert (Developer ID: Yannick Rubini) und mit einem eigenen Update-Schlüssel signiert.
Hier liegt kein Quellcode. Für die Nutzung ist ein Synadata-Konto mit Desktop-Lizenz nötig.
